# Sistema de Gestión de Reservas - Arena Gaming & Esports

Aplicación web desarrollada como **Proyecto Intermodular de 2º de DAW** (Desarrollo de Aplicaciones Web).

## Descripción del Proyecto
Plataforma web centralizada para la gestión de reservas de recursos de alta gama en un centro de ocio digital y gaming (puestos de PC competitivo, simuladores profesionales, zonas de Realidad Virtual y salas VIP).

## Problema que Resuelve
Elimina el caos operativo de los métodos manuales (llamadas o Excel) evitando:
* **Sobresuscripciones (overbooking)** mediante un motor de control de solapamientos.
* **Fallas de hardware:** permite al personal de sala bloquear equipos averiados o en tareas de limpieza (*check-in/check-out*).

## Principales Funcionalidades Previstas
* **Autenticación y Roles:** Permisos diferenciados para Clientes, Personal de Sala y Administradores.
* **Buscador de Disponibilidad:** Consulta en tiempo real de recursos libres por fecha y franja horaria.
* **Motor de Reservas:** Creación, consulta e historial de reservas sin conflictos de horario.
* **Panel de Control Interno:** Gestión de estados del hardware e inventario (CRUD).
